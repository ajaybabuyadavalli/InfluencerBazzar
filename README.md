# InfluencerBazzar

A modern React application for connecting influencers with brands. Built with React, Vite, and Tailwind CSS.

## Features

- ⚡ **Fast Development** - Powered by Vite for lightning-fast HMR
- 🎨 **Beautiful UI** - Styled with Tailwind CSS and glass morphism effects
- 📱 **Responsive Design** - Works seamlessly on desktop and mobile
- 🌙 **Dark Mode Support** - Automatic dark/light theme detection
- ♿ **Accessible** - Built with semantic HTML and accessibility in mind

## Tech Stack

- **React 18** - Modern React with hooks
- **Vite** - Next-generation frontend tooling
- **Tailwind CSS** - Utility-first CSS framework
- **ESLint** - Code linting and formatting

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:5000](http://localhost:5000) in your browser

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
